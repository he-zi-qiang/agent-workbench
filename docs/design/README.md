# 设计稿存档

这个目录放的是**尚未落地的视觉稿**，不是实现。`docs/frontend-design.md` 描述的是
`web/` 里已经存在的东西；这里描述的是有人提议但代码还没跟上的东西。两者冲突时，
以代码和 `frontend-design.md` 为准——存档进来是为了让重构有个可引用的对象，不是
为了给它先发的权威。

## 当前稿：agent-workbench-refactor-2026-08-19.dc.html

2026-08-19 收到的第二版重构稿，连同一份实现交接说明 `handoff-2026-08-19.md`。
Claude design-doc canvas 格式：单文件 HTML，靠 `<x-dc>` / `<sc-for>` 模板和一个
`class Component extends DCLogic` 渲染 1440 × 900 的七个屏——工作台·对话、
工作台·任务、Code、知识库、评测、计算机控制、运行状态。

**要在浏览器里打开它，需要 `support.js` 与它同目录。** 那是 design-doc 的运行时，
没有随稿子存进仓库（一个 69 KB 的生成物，不带许可声明，不适合就这么 vendor 进
来）；交接压缩包里有一份，放到这个目录旁边即可。**不放也能读**：样式、布局、文案
全部内联在标签上，`data-dc-script` 那段里是数据与派生逻辑（`NAV` / `SCREENS` /
`TITLES` / `BEAD_TONES` 与 `renderVals()`）。

### 相对上一版（08-18）的增量

两稿之间的差只有 253 行 diff，集中在三处，`handoff-2026-08-19.md` 的「本稿改动了
什么」逐条写了理由：

- **对话屏的引用画成三种状态**：已读到（证据色引文块）／未读（右端一句
  `点开取原文`）／读不到（警示色，一句不区分原因的话）。表尾从一条「需新接口」
  变成两条，多出的那条说明原文为什么不随答案一起发布。
- **任务时间线的图例多一档「已跳过」**：终态任务上没跑过的阶段不是卡住了，是图
  路过了它，此前它与「还没轮到」共用同一颗空心点。
- **编码屏的产出卡画全了**：动词四选一、`动词 · 大小 · 类型标签` 的 meta 拼法、
  `就地预览` 对 text / image / html 三类展开、两句不同的「看不了」。

第三处在收到这一版之前就已经在主线上了（`web/src/features/code/FileCard.tsx`），
所以稿子这一段是在**追认**代码，不是在要求代码。

### 落地情况

前两处已落地，见 `docs/status.md` 顶部那一节。第三处主线上已有。稿子里仍未落地的
两处：「这次会话批准的应用」需要一条能读到 MCP 进程内 grants 的后端路由；文档标题
需要一条按 `document_id` 取名的读接口——界面上都没有假做，各自写了为什么。
