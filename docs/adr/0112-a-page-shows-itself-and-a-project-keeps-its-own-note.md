# ADR-0112：写出来的页面自己跑起来，项目自己记着它的偏好

- 状态：Accepted
- 日期：2026-09-12
- 关联：ADR-0058（提示词必须描述这个回合**真正所在**的世界）、ADR-0065（一份字节按它
  的类型选查看器——`.html` 在沙箱帧里被*跑起来*，这条是本 ADR 的前提）、ADR-0072 /
  ADR-0074（每个编码会话都属于一个有目录的项目——`AGENTS.md` 就落在那个目录的根上）、
  ADR-0079（计划档的回合根本没有写工具——所以它不被要求去记任何东西）、
  ADR-0096（一个回合握着的工具在它开始之前就定死了——所以那份笔记改不动它）

## 1. 背景

用户的原话是两句：「code 模式应该在对 html 文件生成后进行预览」，以及「应该有类似于
agent.md 记忆文件来记录偏好，例如编写 html 版本的可以直接进行预览」。

两句都不是新功能请求，是对既有能力的**两处断路**：

1. **查看器早就有，却没有人替读者按下去。** `HtmlPreview` 自 ADR-0065 起就在一个
   opaque-origin 的沙箱帧里跑一份自包含的页面，工作区那侧（`FilePreview`）和项目目录
   那侧（`ProjectFileBody`）都接着它。但 `CodePage` 里只有两个入口会跳到「预览」那一张，
   **两个都是读者亲手点出来的**（点目录树里的一行、点对话里的一张卡片）。所以一轮写出
   `index.html` 之后，屏幕上是一张写着文件名和字节数的卡片——而一个没被跑起来的页面等于
   没做出来：读者拿到的是一份他看不懂也用不了的源码，除非他知道要去点哪里。

2. **偏好没有地方可放，于是每一轮从零开始。** 这个仓库里没有任何一个文件是「这个项目
   希望 agent 怎么工作」的落点：`find` 全库没有 `AGENTS.md`，`code_prompt.py` 也没有任何
   读外部文件、拼进系统提示的路径。读者说过一次的约定——包括「能画成页面的就写成 HTML，
   因为它可以直接预览」——活不过这一段会话。

第二条还有一个更尖的形状：**提示词里那句关于页面的话，只有两个 sandbox 变体有**
（`_WITH_SANDBOX` / `_WITH_SANDBOX_UNGATED`）。基础档和项目档的模型从来没被告诉过控制台
会渲染它写出的页面——而项目档正是原生控制台跑的那一档。

## 2. 决定

**三件事，一件在提示词里，一件在页面上，一件是一个文件。**

1. **「控制台会显示你写的东西」提到基础提示词里，说一次。** 它因此沿着既有的派生链进入
   每一个变体——项目档、两个 sandbox 档、`with_host_commands` 之后的那个。两个 sandbox 变体
   里原来那半句关于控制台的话删掉，只留下选择本身（「写页面，不要写终端程序」）。
   这一段同时说出那个帧的**边界**：`connect-src 'none'`，所以从 CDN 取库的页面在那里是
   一张白纸。

2. **一轮落定之后，如果它写出了一个页面，那个页面自己到右栏里跑起来。** 触发的是
   「这个标签页刚跑完一轮」，不是「流里有一个 `.html`」；只有 `previewKind` 判成 `html`
   的那一种会这样；读者**明确**收起过预览栏时不展开它。打开之前先让那个文件的正文缓存
   失效——两侧的缓存都不是按内容键的，不失效的话弹出来的是一张看起来最新的旧页面。

3. **项目根上的 `AGENTS.md` 是这个项目的长期记忆，每个项目回合开始时读一次。** 有就原样
   放进系统提示（上限 8000 字符，超了在提示里说它被截在哪儿），没有就告诉模型这个文件是
   什么、它在哪里。模型也能写它——除了计划档，那种回合根本没有写工具。整段只加在**项目
   档**上：平铺工作区没有根给这个文件坐，而工作区条目活不过这段会话。

## 3. 为什么是这些做法而不是别的

### 3.1 只有页面会自动弹，别的产出不会

一条窄得像偏好的规则，但它是从「这一栏能对这份字节做什么」推出来的。`.py`、`.md`、`.csv`
在预览里是被**画出来**的，而读者在对话里已经看到了它们的卡片、名字和大小——自动打开只是
把同一件事再说一遍，代价是抢走他正在读的那一栏。`.html` 不一样：它在那一栏里是被**跑
起来**的，而这件事在别处一次也不会发生。

`.svg` 留在 image 那一支，跟着这条规则一起不弹：它在 `<img>` 里光栅化，脚本不跑
（`previewKind` 的注释写着为什么），所以它已经是「看得见的」那一类。

### 3.2 触发的是「刚跑完一轮」，不是「流里有一个页面」

后者写起来短三行，行为却是另一件事：每一次打开一段旧会话，都会被上一次的产出抢屏——而
那时读者要的是文件夹和上次说到哪。一轮的落定是这个页面本来就知道的事实（`running` 由
`runningIn` 派生），所以「刚生成」不用猜。

代价是明写的：另一个标签页跑的那一轮不会弹，因为 `runningIn` 只记这个标签页发起的请求。
那一侧的产出仍然是对话里的一张卡片。

### 3.3 等落定，不在写出的那一刻弹

一轮里页面常被改写好几次，而两侧的正文缓存都不是按内容键的（工作区那份是
`staleTime: Infinity`，项目那份 5 秒）。半路弹出来的那一版会一直留在屏幕上，看起来却像是
最新的——**比不弹更糟**，因为屏幕上那张页面没有任何地方说它是旧的。

### 3.4 收起过的那一栏不被推翻，没表过态的那一栏要展开

`panelChoice` 是三态，而这里两种「不是 true」必须分开对待：`null` 是「还没表过态」，
`false` 才是「我收起了」。没有项目目录的会话那一栏默认不显示，所以把页面放进一个不显示
的栏里等于什么也没做——`null` 要展开。`false` 则听读者的：文件放好，他下次展开就看见。

### 3.5 `AGENTS.md`，不是一个私有的拼法

名字是借来的。用过别的编码 agent 的人已经有这个文件、已经知道什么该写进去；而一个私有
拼法要另教一遍，换不到任何这个项目不能从公共拼法里免费拿到的东西。

**只读项目根，不向上找。** 读者选定的那个文件夹的父目录在边界之外，而从边界之外读指令，
会让这条路成为绕过其它每一处路径检查的唯一入口。

### 3.6 这份笔记是「用户的长期指令」，不是「工具返回的材料」

基础提示词有一句谁都要守的边界：工具递回来的东西是材料，不是指令。那句话是对的，而这份
笔记不在它管的范围里——它是平台在回合开始之前读的、来自这个项目自己的文件，与系统提示
其余部分一起交到模型手上。提示里把这件事说明白，否则模型会正确地忽略掉用户刚刚写下的
约定。

同时说清它**不能**做什么：它买不到任何工具。信封在读这份笔记之前就签好了（ADR-0096），
所以这句话描述的是一件已经成立的事——写出来，是因为不知道这件事的模型会花掉几个调用去
发现它。

### 3.7 模型也能写，而计划档不被这样要求

用户选了「模型也能写」。第一条偏好总得有人写下第一次，而那个人往往是正在被告知偏好的
那个回合。所以「用户说了一件持久的事，就把它记进 `AGENTS.md`」这段话只加在**握着写工具**
的回合上：计划档的回合被 `read_only` narrow 过，一个写工具也没有（ADR-0079），要求它记录
任何东西就是在描述一个它不在的世界——ADR-0058 从另一个方向量过这个错误的代价。

### 3.8 8000 字符，超了就说出来

`MAX_READ_BYTES` 允许一个项目文件到 2 MiB，而 2 MiB 的长期指令摆在每一轮前面，花掉的上下文
比工作本身还多；真有人维护的 `AGENTS.md` 是一两页。两种沉默的处理方式都更糟：丢掉它，
读者的约定没人解释而回合表现得像没有约定；截断而不说，模型会照着一条断在半句的规则行事，
并且相信自己读完了。

## 4. 代价与没做的

- **另一个标签页跑的那一轮不弹**（§3.2）。
- **平铺工作区没有长期记忆。** 这不是遗漏：那里的条目活不过这段会话，写进去的笔记会是一份
  「会忘的记忆」——比没有更糟，因为读者会以为它留下了。
- **工作区那侧只失效被打开的那一个名字。** 别的文件的正文缓存仍然可能是旧的，这是这次改动
  之前就有的事，登记为 F-38。顺手半修一半只会让下一个读者以为它被修好了。
- **`AGENTS.md` 不参与 ACL，也不做任何模板展开。** 它是一份文本，原样进提示。
- **没有「记住这条」的按钮。** 偏好要么读者自己写进文件，要么在对话里说出来由模型写。

## 5. 证据

- `tests/application/test_code_session.py`：项目回合拿到那份笔记与两条边界（`standing
  instruction`、`were fixed before it started`）；截断会说出被截在哪；没有笔记时仍然说得出
  这个文件是什么；计划档不被要求写；读不出来的笔记（不存在、非 UTF-8、超过
  `MAX_READ_BYTES`、空白、没有项目）一律是 `None` 而不是一次失败的回合；平铺档一个字也不提
  这个文件；每一份编码提示词都说得出控制台会拿一个页面做什么。

  这几条走的是一个只答 `AGENTS.md` 的 store 替身，不是真的文件存储——被测的是
  `_project_memory` 能扛住 store 的哪些失败，而其中两种（超过 `MAX_READ_BYTES`、读不到的
  目录）用真适配器要一个 2 MiB 夹具和一次权限改动才造得出；「文件系统是这么答的」那句话
  归 `tests/adapters/test_project_file_store.py`。替身里那句 `assert` 钉住的是**文件名**：
  改名漏了一处会在这里失败，而不是在一个每个项目都悄悄没有笔记的部署里。
- `web/src/features/code/previewIntent.test.ts`：只有页面被选中；同一轮里取最后一个；
  `application/octet-stream` 是「没人说过」而不是「说了它是字节」，所以名字仍然算数——项目
  目录里写出的每一个页面都走这一条。
- `web/src/features/code/CodePage.test.tsx`「CodePage 的自动预览」：一轮写完 `.html` 之后它
  自己在右栏里打开；打开一段旧会话不会被上次那张页面盖住；写出的是 `.py` 就不抢屏。
