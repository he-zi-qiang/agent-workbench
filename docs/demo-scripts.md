# 三条演示

评审（[docs/reviews/2026-09-04](./reviews/2026-09-04-product-review.md)）建议作品集只讲三条故事，
其余页面作能力延伸。这一页把三条写成能照着走的脚本：每一步点哪里、看见什么、讲哪一句技术。
主演示控制在几分钟；耗时长的（检索模型下载、环境安装、故障恢复）单独录证据片段。

**先看运行状态页顶上那一块「演示前自检」**：它说「可以开始演示」再开始；说「还不能开始」时
每一项缺失都带着补法。任务 Worker 是 `--demo` 起的合成 Worker 时它会说出来——那时任务会跑完，
但一次真实模型调用都没有发生过，不要拿它演「真实运行」。

准备：`scripts/dev.sh up --with-retrieval`（macOS）或 `scripts\stack.cmd`（Windows），
provider key 存在设置的「模型密钥」里。示例资料放进一个知识库（几份 PDF 或 Markdown 即可，
上传后等文档 Worker 把它们索引完——知识库页会从「处理中」变成「已就绪」）。

## 一、资料问答：答案带来源，刷新后还能核对

1. 侧栏「对话」→ 输入框下选那个知识库。
2. 问一个资料里答得出的问题。**看**：回答下面「已核对来源 · N 条引用」，每条带 `chunk_id`、
   `document_id`、`document_version`。
3. 点开一条引用。**看**：右侧打开的是那一段原文，不是整篇文档。**讲**：读引用是一次新的读取，
   服务端重新做一遍授权（ADR-067），不是回放存下来的原文。
4. **刷新页面**，回到这段对话。**看**：引用还在（2026-09-05 起，历史投影带着回合 id 与引用）；
   再点开一条，仍然打得开。
5. 问一个资料里答不出的问题。**看**：它明说答不上来，而不是编一个像模像样的答案。
6. 可选：在知识库页把那份文档的权限撤掉，回到对话再点引用。**看**：原文打不开了——这是对的。

技术讲解接到：dense + sparse 两路 → RRF 融合 → PostgreSQL ACL 过滤 → 重排 → 发布前的复核
（revision 与 ACL 变了就扣下答案，`AnswerWithheld`）。

## 二、可恢复的任务：分工、批准、下载、以及 Worker 重启后接着跑

1. 侧栏「任务」→ 示例卡「比较方案并生成报告」，或自己说一个要成文件的目标。提交。
2. **看**：标题下面那一行说「正在执行」，执行过程按事件持续同步；有子代理时点「参与的 Agent」。
3. 任务停下来等批准。**看**：行动区变成「停在这里等你决定」，决定在最前面，要批准的草稿就在它
   下面；侧栏「待处理」出现数字——从别的页面回来也找得到它。
4. 批准。**看**：导出，结果上移到最前面，执行过程折成一行；下载报告。**讲**：审批记录是权威账本，
   报告里带着审批 id，可以倒查回是谁批准的。
5. 证据片段（单独录）：任务运行中把 Task Worker 杀掉再起一个。**看**：运行状态页的「任务 Worker
   进程」那格先失联再在线；任务被新的 Worker 换 epoch 领走，从 checkpoint 接着跑，不是从头再来
   ——`TaskClaimed (epoch 2)` 在事件流里看得见。

技术讲解接到：`SKIP LOCKED` 领取、租约/心跳/epoch 栅栏、LangGraph 执行提交时冻结的那个图版本、
每个节点都穿过 Tool Gateway（信封 + 策略）。

## 三、编码交付：改一个文件夹，改前问你，改完能看

1. 侧栏「编码」→ 选一个示例文件夹（或就地新建）。
2. 用示例卡「生成一个文件」，或说一个小改动。
3. **看**：需要跑命令时它停下来问，审批展示具体参数；批准后继续。
4. **看**：本轮步骤里每一次写入都记着文件名；右栏点开改过的文件。
5. 讲清口径：这一轮演示的是**文件修改与预览**；变更 diff、分支和 PR 不在本轮（评审 B 项，
   后续）。
